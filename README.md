# Militari-usa.2010.a
عملیات حک و مانور ایجاد بد افزار بر روی تسلیحات کشور ایالات متحده آمریکا که در عملیات نظامی علیه کشور ایران میخواهد استفاده کند  باید قبل از رها شدن از بمب افکن ها و جنگندها و پهپادهای بدون سرنشین منهدم و منفجر شوند تا از بمباران و قتل عام ملت و زنان و کودکان مظلوم کشور ایران جلو گیری شود نصب بد افزار باید در تمام بمب ها و موشک ها و تسلیحات ارتش کشور ایالات متحده آمریکا خیلی سریع ایجاد شود بدون اینکه کارخانه های سازنده متوجه ایجاد بد افزار یا ویروس بر روی سلاح های تولید خود شوند که قرار است به ارتش آمریکا تحویل دهند که این امر باید تا سال ۲۰۴۰ مدام به روز رسانی و خودکار و روشهای به روزتر انجام شود .انشاالله برای صلح جهانی حضرت مهدی (عج)
